# front_idiomas_danny

Plataforma de aprendizaje de inglés — JumpUp UTE Academy

## Stack
- Kotlin + Jetpack Compose
- MVVM + Hilt
- Retrofit + OkHttp
- Navigation Compose
- Material 3

## Roles
- Admin: panel de administración académica
- Teacher: panel del profesor con gestión de clases, exámenes y recursos
- Student: experiencia de aprendizaje con gamificación

## Base URL
`https://guaman-idiomas-ute.online/api/`
